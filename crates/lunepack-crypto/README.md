# lunepack-crypto

The hashing, signature and signing adapters of lunepack: SHA-256, strict Ed25519 verification, key files (PKCS#8 PEM), an external-command signer and the operating system's random source. Pure Rust.

Part of lunepack; applications normally use the `lunepack` facade crate.

Part of [lunepack](https://github.com/lune-rs/lunepack), a pure-Rust installer, packager and auto-updater framework.
