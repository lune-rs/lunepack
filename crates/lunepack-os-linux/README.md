# lunepack-os-linux

The Linux adapter of lunepack: XDG desktop entries and command links, process restart over `/proc`, and the pieces of a per-machine install (a systemd socket-activated service, a polkit hand-off, a policy file). On other platforms the crate is nearly empty.

Part of lunepack; applications normally use the `lunepack` facade crate.

Part of [lunepack](https://github.com/lune-rs/lunepack), a pure-Rust installer, packager and auto-updater framework.
