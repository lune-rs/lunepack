# lunepack-os-windows

The Windows adapter of lunepack: Start-menu shortcuts and registry entries, process restart, protected directories, the update service's named pipe and the publisher check. On other platforms its public API builds but does nothing.

Part of lunepack; applications normally use the `lunepack` facade crate.

Part of [lunepack](https://github.com/lune-rs/lunepack), a pure-Rust installer, packager and auto-updater framework.
