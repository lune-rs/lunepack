# lunepack-os-macos

The macOS adapter of lunepack: process restart over libproc, LaunchAgent and LaunchDaemon integration, the pieces of a per-machine install and the code-signing publisher check. On other platforms the crate is nearly empty.

Part of lunepack; applications normally use the `lunepack` facade crate.

Part of [lunepack](https://github.com/lune-rs/lunepack), a pure-Rust installer, packager and auto-updater framework.
